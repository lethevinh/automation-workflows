# Zapier Automations

Zapier has no clean JSON export, so each folder ships step-by-step docs plus
annotated screenshots of every Zap step:

```
<zap-slug>/
├── README.md        # Problem → trigger/actions walkthrough → results
└── assets/          # Per-step screenshots, task-history proof
```
