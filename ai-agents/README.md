# AI Agents

Agent setups that plug into real business workflows — classification,
drafting, enrichment, orchestration. Each folder holds everything needed to
reproduce the agent:

```
<agent-slug>/
├── README.md        # Problem → agent design → evals/results
├── prompts/         # System & task prompts, versioned
├── config/          # Model, tool, and routing configuration
└── .env.example
```
