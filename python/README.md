# Python Automation Scripts

Standalone scripts and small pipelines — the pieces that sit next to a
workflow engine when a native node isn't enough (OCR, data cleanup, custom
API clients, batch jobs).

Each project is packaged and tested:

```
<script-slug>/
├── README.md          # Problem → usage → results
├── src/
├── tests/
├── pyproject.toml     # or requirements.txt
└── .env.example
```
