# Case Studies

Deep-dives into real projects: the client's problem, the automation I built,
and the measured result. One file per case study, named
`<yyyy>-<client-or-domain>-<slug>.md`.

## Template

1. **Context** — who the client is, what their process looked like
2. **The problem** — time/money cost of the manual process
3. **What I built** — architecture, tools, decisions & trade-offs
4. **Results** — numbers before vs after
5. **What I'd do differently** — honest notes
